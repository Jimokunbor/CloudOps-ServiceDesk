# CloudOps ServiceDesk

## Project Description

CloudOps ServiceDesk is an enterprise-style IT Service Management (ITSM) platform developed to demonstrate modern software engineering, cloud engineering, DevOps, Infrastructure as Code (IaC), cloud-native architecture, and enterprise operational practices.

The platform simulates a real-world IT Service Desk where employees submit support requests, technicians resolve incidents, and administrators manage users, operations, and infrastructure.

The project is being engineered as a production-oriented portfolio application that demonstrates the complete software delivery lifecycle, from backend development and database design to infrastructure automation, cloud deployment, monitoring, and continuous delivery.

It showcases the practical skills expected of Cloud Engineers, DevOps Engineers, Platform Engineers, Site Reliability Engineers (SREs), Backend Engineers, and Infrastructure Engineers.

---

# Project Objectives

CloudOps ServiceDesk aims to:

- Build a production-ready IT Service Management platform.
- Demonstrate enterprise backend development using FastAPI.
- Implement secure authentication using JWT and OAuth2.
- Apply Role-Based Access Control (RBAC).
- Build a scalable RESTful API.
- Design and manage relational databases using PostgreSQL.
- Automate database migrations with Alembic.
- Demonstrate Infrastructure as Code.
- Automate infrastructure provisioning.
- Containerize enterprise applications.
- Deploy workloads using Kubernetes.
- Build automated CI/CD pipelines.
- Implement enterprise monitoring and observability.
- Deploy production workloads to Amazon Web Services (AWS).
- Follow enterprise software engineering best practices.
